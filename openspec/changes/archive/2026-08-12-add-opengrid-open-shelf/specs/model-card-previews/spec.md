## ADDED Requirements

### Requirement: Open Shelf has a canonical Desk preview asset

The visible Desk catalog entry for `opengrid-open-shelf` MUST reference `/model-previews/opengrid-open-shelf-desk.png` with non-empty dimensions and alternative text identifying the Open Shelf. The asset MUST be generated by the existing preview capture workflow from the Open Shelf generator using the Desk preset and a clean storage context. The asset MUST remain presentation-only and MUST not be used by Worker validation, generation, or export.

#### Scenario: Preview capture includes Open Shelf

- **WHEN** the model preview capture workflow derives its targets from the visible catalog
- **THEN** it MUST visit `/cad/opengrid-open-shelf?system=desk&preview=thumbnail`
- **AND** it MUST write and verify `opengrid-open-shelf-desk.png`

#### Scenario: Missing Open Shelf preview fails verification

- **GIVEN** the Open Shelf preview asset is missing, empty, or undecodable
- **WHEN** preview verification runs
- **THEN** verification MUST fail and identify the Open Shelf entry or asset path

#### Scenario: Preview remains separate from CAD identity

- **WHEN** the Open Shelf preview is regenerated
- **THEN** only the static presentation asset and metadata MAY change
- **AND** the model id, route, Worker builder, parameter contract, STEP export, and STL export MUST remain unchanged
